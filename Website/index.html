Object Relationship Explorer …

Unity / VRChat の Scene・GameObject・Component・Prefab・Asset・Udon の関係を索引化し、選択と連動してグラフ表示する Editor 専用拡張です。

VCC / ALCOM で導入（VRChat プロジェクト）

Add to VCC

ボタンが動かない場合は、VCC の Settings → Packages → Add Repository に次の URL を登録してください。

登録後、プロジェクトの Manage Project から「Object Relationship Explorer」を追加します。

Unity Package Manager で導入（Git URL）

  1. Window → Package Manager → 左上の「+」→ Add package from git URL…
  2. 次の URL を入力して Add

VRChat SDK が無いプロジェクトでも Unity 標準の解析は動作します。Unity 2022.3 以降。

使い方

Window → Analysis → Object Relationship Explorer を開きます。詳細は README を参照してください。
