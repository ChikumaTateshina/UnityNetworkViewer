UnityNetworkViewer …

「このオブジェクトは、どこから参照されていて、何を動かしているのか」を、Unity Editor 上のグラフで確認するための拡張です。

Scene・GameObject・Component・Prefab・Asset の関係に加え、VRChat ワールドの UdonBehaviour / UdonSharp / Udon Graph が操作する対象も推定して表示します。

どんなツール？できること導入使い方表示の見方注意点

どんなツール？

Unity の Inspector で分かるのは「このオブジェクトが何を参照しているか」までで、「どこから参照されているか」は分かりません。 UnityNetworkViewer はプロジェクト内の参照関係を索引にまとめ、Hierarchy や Project でオブジェクトを選ぶだけで、その周りの関係をグラフで表示します。

表示のイメージ図です（実際の画面ではありません）。選んだオブジェクトを中心に、左に参照元、右に参照先が並びます。

できること

選択と連動して表示

Hierarchy・Scene View・Project で選んだオブジェクトの関係をすぐ表示します。グラフ上でクリックすると、Unity 側でもそのオブジェクトが選択されます。

参照元・参照先を両方向に

Inspector の参照、配列の要素、UnityEvent の呼び出し先、親子関係、Component を、何段先まで辿るか（0〜5）指定して表示します。

Prefab の関係

Prefab Instance と元の Prefab、Variant、入れ子の Prefab、Override の有無を表示します。

開いていない Scene も検索

開いていない Scene の中身も索引するので、Scene をまたいで「どこで使われているか」を検索できます。

VRChat の Udon に対応

UdonSharp と Udon Graph を静的に解析し、各インスタンスの変数設定と結び付けて、SetActive や SendCustomEvent の操作先を推定します。

問題の発見

Missing Reference、参照先を特定できない呼び出し、循環参照、どこにもつながらないオブジェクトを一覧で表示します。

根拠を表示

線ごとに、どのプロパティやソースのどの行から分かった関係なのかと、確度（確定 / 推定 / 未解決）を表示します。

検索とエクスポート

名前・型・Scene・メソッド名などで検索できます。表示中のグラフは JSON / GraphML / SVG で書き出せます。

こんなときに

  • オブジェクトを消したり名前を変えたりする前に、どこから使われているか確かめたい
  • 他の人が作ったワールドのギミックが、どのスイッチから何を動かしているのか追いたい
  • Missing になった参照を、Scene をまたいでまとめて洗い出したい
  • Prefab の Override がどこで入っているか確認したい

導入

VCC / ALCOM（VRChat プロジェクト）

Add to VCC

ボタンが動かない場合は、VCC の Settings → Packages → Add Repository に次の URL を登録してください。

登録後、プロジェクトの Manage Project から「UnityNetworkViewer」を追加します。

Unity Package Manager（Git URL）

  1. Window → Package Manager → 左上の「+」→ Add package from git URL…
  2. 次の URL を入力して Add

使い方

  1. ウィンドウを開く: メニューの Window → Analysis → UnityNetworkViewer。開くと解析が始まり、まず開いている Scene、続けてプロジェクト全体を裏で索引します（作業は止まりません。Unity の Progress からキャンセルできます）。
  2. オブジェクトを選ぶ: Hierarchy や Project でオブジェクトを選ぶと、その周りの関係がグラフに出ます。
  3. 範囲を調整する: 左のパネルで、方向（参照元 / 参照先 / 両方）、何段先まで辿るか（0〜5）、関係の種類、確度を絞り込みます。
  4. 詳しく見る: ノードを選ぶと、右のパネルに参照元・参照先の一覧と、その関係の根拠が出ます。ダブルクリックで Unity 上の位置へ移動します。
  5. 検索する: 上部の検索欄で探します。空白で区切ると AND、先頭に - を付けると除外です。
    door type:Animator scene:Main method:SetActive flag:Missing

操作: ドラッグでパン、ホイールでズーム、F で選択中のノードへ移動、A で全体表示。ノードを右クリックすると、経路の表示、隣接ノードの展開、ピン留め、ID のコピーなどができます。

表示の見方

選択中（太枠） 参照元 参照先 Prefab 関係 親子 推定（破線）
確定Inspector の設定値など、シリアライズされたデータから分かる関係です。参照があることを示すもので、実行時に必ず使われるという意味ではありません。
推定スクリプトの静的解析から推定した関係です。if の中など、条件付きで実行される処理を含みます。
未解決Missing Reference や GameObject.Find のように、参照先を特定できない呼び出しです。

色だけでなく、線の種類・矢印・ラベルでも区別しています。選択から2段目以降は、離れるほど薄く表示されます。

動作環境と注意点

Unity2022.3（2022.3.22f1 で確認）
VRChat SDK任意。Worlds 3.4.0 以上で Udon の解析が有効になります（3.10.5 で確認）。SDK が無いプロジェクトでも、Unity 標準の解析は使えます。
安全性解析は読み取りのみです。Scene や Prefab を変更済み（Dirty）にしたり、保存したり、勝手に開いたりしません。開いていない Scene を開くのは、確認ダイアログで選んだときだけです。
ビルドEditor 専用です。ゲームのビルドや VRChat へのアップロードには含まれません。
制限開いていない Scene の解析は、テキスト形式（Force Text）の Scene が対象です。UdonSharp の解析は構文だけを見ているため、基底クラスのフィールドやプロパティの連鎖などは「未解決」と表示されます。
